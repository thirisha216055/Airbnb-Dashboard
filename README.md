🏡 Airbnb Dashboard - Tableau Visualization

This repository contains an interactive Tableau dashboard that visualizes key insights from Airbnb listings. The goal is to help stakeholders understand patterns in property types, pricing trends, availability, and host performance for strategic decision-making.



 📊 Dashboard Overview

The Airbnb Dashboard provides a comprehensive visual analysis of Airbnb data from Chicago, including:

- Property type distributions
- Price trends by neighborhood and property type
- Availability and seasonal trends
- Host listing counts and ratings



 📁 Datasets

The datasets used in this project are located in the `/data` folder:

| File Name             | Description                                 |
|--||
| `listings_chicago.csv` | Raw Airbnb listings data                  |
| `listings_cleaned.csv` | Cleaned dataset used for dashboard        |
| `listings_no.csv`      | Listings without missing values           |
| `reviews_chicago.csv`  | Review data including dates and comments  |

📌 Source: Datasets are based on publicly available Airbnb data from [Inside Airbnb](http://insideairbnb.com/).



 ✨ Features

- 🔍 Filter by room type, neighborhood, and price range
- 📈 Trend analysis of average prices over time
- 🧹 Insights into top-performing hosts and review activity
- 📌 Interactive maps and bar charts for visual storytelling



 🛠️ Tools & Technologies

- Tableau: For data visualization and dashboard creation
- Excel / Python: For data preprocessing and cleaning
- GitHub: For version control and project sharing
